# Quirky Chess Engine

A very customizable local two-player Javascript-based Chess Engine. The 231st Summer of Making Project of **all time**.

## How to Localhost?

If you're on VSCode, you can use **Five Server** or the **Live Server** extension to statically and locally host this.

## How do I play?

I recommend you to play chess.com before you start using Quirky Chess Engine- you **will** be confused if you don't know how to play Chess.
